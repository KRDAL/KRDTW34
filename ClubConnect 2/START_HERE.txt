CLUBCONNECT — MP1 + MP2

OPEN AND RUN
1. Extract the entire ZIP. Keep the ClubConnect folder together.
2. Double-click ClubConnect.xcodeproj inside that folder.
3. Select the ClubConnect scheme at the top of Xcode.
4. Choose an installed iPhone Simulator as the run destination.
5. Press Command-R, or click the triangular Run button.

The deployment target is iOS 15.0. Use Xcode 14 or newer with an installed
iOS Simulator runtime. This project has no CocoaPods or third-party packages.
A development team is not needed for a Simulator build. For a physical iPhone,
select your own team in Signing & Capabilities and use a unique bundle ID.

TRY THE TWO MODULES
- Welcome: enter KRD, choose reminders ON/OFF and Member/Officer.
- Join the Club: opens the MP1 confirmation. The Back button returns to Welcome.
- Browse Clubs: opens MP2's directory. Tap a row to see its details together
  with the name, role and reminder preference from Welcome.
- Tap +: enter a name and category, then Add.
- Terminate the app and launch it again on the SAME Simulator: your welcome
  values and any added club should remain. Join or Browse saves form changes.
- Blank or whitespace-only names use "Club Member" in the confirmation.

IMPORTANT BEFORE SUBMISSION
The project files were checked structurally here. Xcode, Apple's SDK and an
iPhone Simulator were unavailable, so no native build or runtime test was
performed here. Use the included Simulator checklist on your Mac, and take
real screenshots. No simulated screenshots or fabricated test results are
included. The README identifies the remaining submission steps.
